# Contributing Guide

Thank you for contributing to the Enterprise Observability Platform.

---

## Development Workflow

1. Update Documentation
2. Create Feature Branch
3. Implement Feature
4. Unit Tests
5. Integration Tests
6. Update Changelog
7. Create Pull Request

---

## Coding Standards

- Python 3.12+
- Type Hints
- Dataclasses
- Docstrings
- Logging
- Unit Tests Required

---

## Design Principles

- Source Agnostic
- Configuration Driven
- Stateless
- Field Based Validators
- No Vendor Specific Logic

---

## Commit Format

feat:

fix:

docs:

refactor:

test:

chore:

---

## Pull Request Checklist

- Documentation Updated

- Unit Tests Added

- Existing Tests Passing

- ADRs Reviewed

- Changelog Updated

- No Breaking Changes
