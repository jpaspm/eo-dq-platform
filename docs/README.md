# Enterprise Observability Data Quality Engine (EO-DQ)

## Overview
Source-agnostic Enterprise Observability Data Quality platform.

## Flow
Sources -> Collector -> TelemetryDataset -> DQ Engine -> JSON Reports -> S3 -> Grafana

## Principles
- Source Agnostic
- Configuration Driven
- Immutable Runtime
- Field-based Validators
- Stateless Execution
- JSON-first Reporting
